## 0. what this project is, and what it is not
  samples/consumer-proof is a windowless WPF application whose only reference is
  <PackageReference Include="Trustsoft.NotifyIcon" Version="1.0.0" />, restored from
  artifacts/ through its own nuget.config (which clears every inherited source). It is absent
  from Trustsoft.NotifyIcon.sln and carries its own empty Directory.Build.props, so it inherits
  neither a project reference nor a build setting of the repository that produced the package.
