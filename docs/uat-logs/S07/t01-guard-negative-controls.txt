# S07/T01 raw evidence: negative controls for the packaging guards
date: 2026-09-21T14:17:51+03:00
machine: unknown / MINGW64_NT-10.0-26200
framework: 10.0.401

A guard that has never been seen to fail is not a guard. Each control below breaks exactly one
invariant, records the failure the test reports, and then restores the file it touched; cmp
proves the restore at the end and the same guards run green afterwards.

Method note: each dotnet test run is captured into a variable and filtered afterwards. Piping a
running build straight into head truncates it, and a truncated build leaves
src/Trustsoft.NotifyIcon/obj/project.assets.json unreadable - the next --no-restore run then fails
with NETSDK1060 instead of running the test. That was measured, not assumed.
